Lunaria

Java JavaFX MVC

Description du projet

Lunaria était mon projet final de première année en BUT Informatique. Objectif : créer un jeu 2D inspiré de Terraria en trinôme, avec Java et JavaFX.

Sans librairie de jeu autorisée, nous avons développé de zéro la physique (gravité, déplacement), une carte procédurale, une IA d'ennemis, ainsi qu'un système de combat, de craft et d'inventaire. Le code a ensuite été refactoré en s'appuyant sur des design patterns pour en améliorer la structure.
