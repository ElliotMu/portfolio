MaBuvette

PHP HTML CSS SQL Bootstrap

Description du projet

MaBuvette est un projet réalisé lors de mon 3e semestre en BUT Informatique. Objectif : créer un site web responsive en PHP permettant de gérer des buvettes associatives.

Chaque utilisateur peut s'inscrire à une buvette et y commander des produits. L'application facilite les transactions avec les buvettes, en utilisant bien sûr une monnaie fictive.

Le site s'articule autour de quatre rôles :

  • Barman — reçoit les commandes des clients, les prépare et les valide.
  • Gestionnaire — gère l'inventaire, les produits, les adhérents et leurs rôles, et consulte les revenus de la buvette.
  • Client — ne dispose d'aucun privilège particulier sur une buvette.
  • Super admin — accepte ou décline les demandes de création de buvettes et peut en supprimer une si besoin.
