KanaApp

React CSS

Description du projet

KanaApp est une application réalisée lors des cours de développement web, qui m'a permis d'apprendre à développer un site en React et de découvrir diverses méthodes telles que les card properties et les hooks.

L'objectif de ce site est de proposer une visualisation de l'alphabet japonais, (Hiragana et Katakana), ainsi qu'un quiz permettant de s'autotester, avec un suivi du record et du nombre d'essais effectués.
